# 📊 Intern Project: End-to-End Data Analysis & Monthly Dashboards

## 📌 Project Overview
This repository presents an end-to-end data analytics workflow covering raw data inspection and cleaning in Python, structured database querying in SQL, and monthly performance visualization for January, February, and March.

* **Live Dataset:**
  * [📊 January Dataset (Google Sheets)](https://docs.google.com/spreadsheets/d/1mCX2VamyUNeYG9hC0F4Ft6l_dC9fGNGPv3MWgLWehIw/edit?usp=sharing)
  * [📊 February Dataset (Google Sheets)](https://docs.google.com/spreadsheets/d/1z7wah-lh-6Vz0k7gm5Ad_AxeciZJEfIKmOxgcOeEXhk/edit?usp=sharing)
  * [📊 March Dataset (Google Sheets)](https://docs.google.com/spreadsheets/d/1cmvhiK3uaURUzYF2T1cmcolj18q1gnoVsWmpKSrYOrA/edit?usp=sharing)
* **Tools Used:** Python, SQL, Google Sheets

---

## 🛠️ Workflow & Repository Structure

### 1. Data Preparation (Python)
* **[`Data_Cleaning_&_Data_Inspection.ipynb`](./Data_Cleaning_%26_Data_Inspection.ipynb)** – Handles data exploration, missing values, duplicates, and formatting standardization.
* **[`Data_Loading.ipynb`](./Data_Loading.ipynb)** – Prepares and loads the cleaned dataset into the database.

### 2. Data Analysis (SQL)
* **[`SQL_DataLoading.sql`](./SQL_DataLoading.sql)** – Database schema creation and initial data ingestion scripts.
* **[`jan_operations.sql`](./jan_operations.sql)** – SQL queries and operational analysis for January.
* **[`feb_operations.sql`](./feb_operations.sql)** – SQL queries and operational analysis for February.
* **[`mar_operations.sql`](./mar_operations.sql)** – SQL queries and operational analysis for March.
